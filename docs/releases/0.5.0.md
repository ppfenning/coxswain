# 0.5.0

Cut on 2026-09-08, the same day as `0.4.0`. Every component is tagged `v0.5.0` in lockstep;
`coxswain-tools` is published to PyPI from that tag. Status: **beta**; nothing here breaks a `0.4.0`
install. The release completes the run stats store that `0.4.0` shipped as a preview, and fixes two
headline numbers that were wrong on two thirds of rows.

## coxswain-tools

- `cox stats roles` reports, per role and model, calls, calls attributed to a ticket, landed rate,
  attempts-to-land and cost per landed task, with a coverage figure on every row; `cox stats explain
  <role>` and `cox stats series` (tools #107, #108).
- The calls-to-task join is applied where `sum(fix_loop.attempts)` equals the run's build count — 553 of
  670 build calls on the development corpus — and refused where it does not, marked
  `join_confidence='none'` (tools #106).
- `failure_class` is scoped by role, so 2,857 non-patching calls no longer read `empty_patch`; `landed`
  is read from the work store, so `landed_rate` reads 0.95 instead of 0.06 (tools #109).
- `runs.provider_profile` is populated at ingest and `roles`/`series` group by
  `(cartridge_sha, provider_profile)` (tools #110); the work-store lookup that resolves 261 outcomes (tools #111).
- `pyproject` bumped to match the tag (tools #112).

## coxswain-graphs

- Every surface a decompose names must resolve to a real path or a `(new)` path under an existing
  directory; tasks spanning repositories split into sibling initiatives with `blocked_on` (graphs #60).
- An intake file whose frontmatter already carries an `initiative` is linked, not re-queued (graphs #61).

## coxswain-cartridges

- `decompose` runs at a `$2.00` ceiling: it runs once per initiative, and its four costliest calls were
  all deaths recovered from traces (cartridges #55).

## coxswain

`releasable.yml` was invalid YAML since `0.4.0` and had never run; fixed (#36). Manifest and notes (#37, #38).

## Known gaps

- `cost_per_landed` reads `0.0`: the call-cost rollup onto tasks is not written; filed first in line.

## Components

`coxswain-tools` carries the stats store; `coxswain-cartridges` the decompose ceiling; `coxswain-graphs`
the decompose fixes; `coxswain` the `releasable` fix. `coxswain-crew` is unchanged since `v0.4.0`.
