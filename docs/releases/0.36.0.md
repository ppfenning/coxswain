# 0.36.0

Cut on 2026-10-07. Status: **beta**. The operations release, and the start of the feature freeze before 1.0: from
here on only defects, hardening and docs. The store is backed up daily to Garage and a monthly drill proves a restore,
the notifier pushes needs-you events and milestones to a phone, `brew install` brings towpath along with `cox`, the
model tiers follow the newest model in each family, and the chair stops relaunching work it cannot build.

**Operations.** A daily job dumps the store, uploads the dump to the Garage bucket the lake already uses and keeps 14
days; a monthly drill restores the newest dump into a scratch database and compares row counts with the live store.
The notifier's chair wiring is in, so a configured `notify:` channel (ntfy) receives needs-you events and milestones.
The Forgejo forge is wired: a repository whose origin is on the configured Forgejo host lands through it. The tap step
writes the towpath download into the formula, so the next `brew upgrade cox` installs `towpath` and `coxtop` too
(coxswain #256).

**Models.** The provider tiers name model families (`haiku`, `sonnet`, `opus`) and the loader resolves each to the
newest catalog row in its family, so a new model needs one catalog row and no tier edit. A refresh lists the vendor's
models and reports one newer than the catalog. The standard tier moved to Sonnet 5.5.

**A chair that does not spin.** An initiative whose repository has a land in flight is not launched, a land the forge
refuses backs off instead of being re-planned every tick, and an initiative is capped at a few launches an hour, with
one note when a relaunch keeps ending the same way. An epic run reports `paused` and `awaiting_land` through its exit
code instead of quarantining, a session limit inside any node pauses the run, and an OAuth refresh race between two
runs on one machine is retried as a harness fault. A dry-run tick takes about 25 s instead of about 108 s.

**Upgrading from 0.35.0.** Nothing migrates and the store schema is unchanged. Restart the chair loop. An unknown key in
the profile now warns instead of stopping the loop. To arm the backup on the store host, run
`ops/store-backup/install.sh` from coxswain-tools. If you installed towpath with cargo, the brew copy lands in
Homebrew's bin; keep whichever comes first on your PATH.
