# 0.23.1

Cut on 2026-09-28. `coxswain-cartridges`, `coxswain-graphs` and `coxswain-tools` are tagged `v0.23.1`.
`coxswain-crew` stays pinned at `v0.12.0`. `coxswain-tools` is published to PyPI from its tag. Status: **beta**.
This patch settles the decisions Pat made the morning after 0.23.0, and it carries two headlines.

**A build checks its cost at every guide and stops at a $6 failsafe.** A build runs in slices. Each slice stops at
the guide, the build's measured shape (about $1.90 today), where the harness judges go or no-go: the session can
resume, the partial work stays inside the task's surfaces, and each slice changed something. A build that passes
resumes, as many times as it takes, until its session's cumulative spend reaches the $6 failsafe; then it is refused
with a split recommendation. The weekly cap stays the global bound.

**Run logs keep a 7-day lookback.** `cox lake sync` archives each ended run's text log and call log older than
`log_retention_days` (default 7) beside the traces on the object store, reads each copy back, and only then removes
the local file. The loop's trace prune keeps the same number of days.

Two decisions need no code. The resident chair never pushes the workspace: the store is the board. Postgres stays the
setup default: the shared provider profile names the fleet's store, and a machine falls back to SQLite only when no
store is named.

**Upgrading from 0.23.0.** Nothing to change. To keep logs longer, set `log_retention_days` in the routing profile,
after every machine runs 0.23.1, since an older `cox` refuses a key it does not know. A provider profile that keeps
its own copy of the Claude Code profile adds `role_ceiling_usd: {build: 6.0}` beside `role_budget_usd`.

## coxswain-tools

- Run logs past `log_retention_days` (default 7) are archived by `cox lake sync` beside the traces root and then
  removed locally; the housekeeping trace prune uses the same number (tools 8185edd, 1ae3b58).

## coxswain-graphs

- A role's `role_ceiling_usd` caps a session's cumulative spend, each slice stops at the guide for a go/no-go
  checkpoint, and a build resumes at every checkpoint that passes until the failsafe (graphs ee08f15, 4027412).

## coxswain-cartridges

- The Claude Code provider profile sets `role_ceiling_usd: {build: 6.0}`, and a work item may raise its own guide up
  to $6 (cartridges fd48dfc, 0eb5e77).

## Components

`coxswain-graphs` carries the checkpoints, `coxswain-tools` the log retention, and `coxswain-cartridges` the failsafe
number. `coxswain-crew` is unchanged.
