# 0.25.1

Cut on 2026-09-29. `coxswain-graphs` and `coxswain-tools` are tagged `v0.25.1`. `coxswain-cartridges` stays pinned at
`v0.23.1` and `coxswain-crew` at `v0.12.0`. `coxswain-tools` is published to PyPI from its tag. Status: **beta**.
This patch fixes a 0.25.0 regression that broke every runner except Claude Code, and it stops the build checkpoint
from sending back good builds. It carries two headlines.

**Every runner works again.** 0.25.0 passed the pause hook to every style pass and gate model-arm apply, but only the
Claude Code runner accepted it, so the Anthropic runner (the default when a profile names no runner), the
OpenAI-compatible runner and System One failed there with a `TypeError`. Every runner now takes the hook and waits
before its request when the run is paused, and a test checks that every runner accepts every keyword of the runner
protocol.

**The build checkpoint judges scope on the change, not its tests.** A checkpoint sent a build back as soon as its
partial work touched a file outside the task's surfaces, and on 2026-09-29 it did so 37 times, 13 of them for nothing
but tests, fixtures or snapshots. Tests, test fixtures and `.snap` files now count as inside a task's surfaces, a
surface ending in `/` covers the files under it, and untracked scratch files a build drops (probes, diffs, outputs)
are ignored. Review still judges all of them.

**Upgrading from 0.25.0.** Nothing to change: no store migration. Restart the chair loop after upgrading `cox`.

## coxswain-graphs

- Every runner accepts the runner protocol's pause hook, and a conformance test checks every protocol keyword
  (graphs #640).
- Tests, fixtures, snapshots and `dir/` surfaces count as inside a task's surfaces at the build checkpoint
  (graphs #643); untracked scratch files are ignored there (graphs #641).
- The decompose corrects test paths in a task's surfaces to the repository's layout and drops needs that name tasks
  outside the initiative (graphs #636).

## coxswain-tools

- An initiative decomposed into no tasks is a needs-chair item on the loop's plan (tools #1242).

## coxswain

- The 0.25.0 notes are corrected: `cox runs pause` and `resume` fail in 0.25.0, and the runner regression above is
  listed under Known issues (coxswain #206).

## Components

`coxswain-graphs` carries the runner and checkpoint fixes, `coxswain-tools` the empty-decompose item, and the umbrella
the notes correction. `coxswain-cartridges` and `coxswain-crew` are unchanged.
