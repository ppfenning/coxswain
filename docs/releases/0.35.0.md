# 0.35.0

Cut on 2026-10-06. Status: **beta**. Lands no longer drop work: a phase land includes every approved task of the
phase or stops and says which one is missing, and a quarantine raised while merging a phase reaches the store. A
land that turns main red is reverted and its initiative quarantined. Each release now proves a clean install and an
upgrade from the tap before the tap pull request merges (coxswain #248, coxswain #249, coxswain #251), and a cut
pushes a notification when one is configured (coxswain #252).

**Lands that never drop work.** A phase land gathers every task approved for the phase, from this run or an
earlier one, and refuses to squash a phase branch that is missing one; a task is marked done only once its commit
is on main. Every quarantine in an epic run reaches the store, a conflicting phase merge included. A task approved
and then quarantined for its code or its ticket no longer blocks its own relaunch. A timed-out post-land smoke
check is inconclusive rather than a red main.

**A red main is reverted.** After a land, the chair watches main's checks; when they fail, it opens a revert pull
request for that land and quarantines the initiative, and two reverts in a row stop its relaunches.

**towpath.** Each row names its project, the queue groups by project, `towpath --version` and `cox --version`
print their versions without starting a screen, and the spend detail charts the real week and a rolling five-hour
window.

**Started, not yet wired.** The Forgejo forge client and its operations are on main and selectable with
`forge: forgejo`; detecting a Forgejo origin automatically lands in 0.36. The notifier's events and cards are on
main; the chair loop starts sending them in 0.36. The chair's ticket widening has its rules and ticket text but
not its handoff wiring. The release tool can write a towpath download into the formula, and the tap step starts
passing it in 0.36.

**Upgrading from 0.34.0.** Nothing migrates and the store schema is unchanged. Restart the chair loop to pick up
the new land and revert rules.
