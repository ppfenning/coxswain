# 0.1.0-beta.1

The first Coxswain release, cut on 2026-09-05 — the day the platform took its name. Every component is
tagged `v0.1.0-beta.1` in lockstep; `coxswain` and `coxswain-tools` are published to PyPI by trusted
publishing. Status: **beta**: the loop works and runs itself daily, the interfaces still move. Deprecated
for one release: `agent-tools` as an alias for `cox`, and `cast` as an alias for the cartridge's `crew` key.

Install the platform from one manifest, point it at a repository, describe a change: Coxswain files it,
plans it, builds it in a worktree under a budget, has two independent reviewers argue about it, arbitrates
them, runs the project's tests as evidence, and hands you a pull request. You merge.

## coxswain

`manifest.toml` is the single source of truth for what a release installs, with lockstep pins. The docs site: MkDocs Material with `mike` versions, a CLI reference generated at build time from `cox --help`, terminal screenshots captured with Rich, every graph's diagram pulled from the graphs repository at build time, and the animated racing-eight header. `publish.yml`: PyPI trusted publishing on `v*` tags, no token stored anywhere.

## coxswain-cartridges

- The `coxswain` Claude Code plugin: a session-start hook that prints the docket, a statusline, and the
  `/launch`, `/land`, `/runs`, `/intake` and `/regatta` commands.
- `cartridge init <team>` writes a minimal team cartridge; `cartridge.d/*.yaml` fragments fold over each
  layer, tighten-only, refusals naming the fragment.
- `crew` replaces `cast` as the seats key; `policy.dispatch.max_in_flight` bounds concurrent runs;
  `policy.plan_tier` derives a task's tier from its surfaces; a work item may carry `budget_usd`.

## coxswain-graphs

- The coxswain graph's docket reports runs in flight and free slots, and the driver invokes only that many.
- `validate_chunk` can ask for evidence by path, which the harness reads once and attaches before asking
  again — the end of the blind "need to verify" quarantines.
- A build that hits its ceiling raises `BudgetStop` with the session and the spend, keeps the partial
  diff, and the lifecycle decides go/no-go deterministically before continuing in the same session.
- The plan competition and attack run only where a task's tier reaches `plan_competition.min_tier`.
- Every graph's page and diagram are generated from its docstring, with a freshness test.

## coxswain-tools

- `cox` is the operator command; bare `cox` opens a Coxswain session. `cox install`, `cox upgrade`,
  `cox versions`; `cox setup doctor` and the `cox setup` screen; `cox runs events|top|land`; `cox route`
  files work, launches the harness detached and reports status; maintainer commands under `cox dev`.

## coxswain-crew, coxswain-hud, desktop

- `coxswain-crew` renamed from `agent-cast`, no behaviour change. `coxswain-hud` renamed from
  `agent-voice-hud`, no feature work. Desktop planned. Both left the product in `0.2.0`.

## Across every repository

- Ruff runs in CI with one shared rule set, mirrored by pre-commit.
