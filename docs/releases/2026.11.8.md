# 2026.11.8

Cut on 2026-11-13. Status: **beta**. A patch release for two faults found the first night 2026.11.7 ran on a chair. A host whose Claude token lives in the environment, not in coxswain's own token file, was marked login-lapsed and taken out of placement. And two phase merges that could not move, because their branches had diverged from origin, sat at the head of the lander's queue and starved every later phase merge.

**The token.** With no token file, a non-empty `CLAUDE_CODE_OAUTH_TOKEN` in the environment is now the token. `cox setup token status` runs its checks with it and names the source, never the value, and the doctor's `claude token` row passes.

**The lander.** A phase merge left waiting no longer uses the pass's cap, so a waiting item cannot hold back the ones behind it. A land already worked this way.
