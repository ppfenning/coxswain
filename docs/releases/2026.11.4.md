# 2026.11.4

Cut on 2026-11-04. Status: **beta**. This release starts the waves-of-phases work: an initiative is planned as waves of phases, independent phases run in lanes of their own at once, and tasks run in parallel inside a phase. Releases are now cut from a short-lived release branch, so main keeps landing work while a cut runs. Towpath gains a spend view by day and budget period, reading the `budget` object that 2026.11.3 put in the feed. The rest is a handful of harness fixes from the chair driving the fleet through 2026.11.3.

**Waves of phases (#626, and the parallel-lanes half of #613).** A phase depends on another when one of its tasks needs an unfinished task there, and the phases fall into waves: each wave holds the phases whose parents all sit in earlier waves. The epic driver now runs as a lane scheduler. Independent phases run side by side, a task in a later level starts while an unrelated earlier task still builds, and a quarantined task blocks only its dependents. Two phases that declare the same surface run one after the other, with a reason naming the shared paths. Each phase sees the shared runner through its own view, with its own worktree, repo digest and check commands, and the runner closes once after every phase. A phase can be built in several calls; a task an earlier call approved and merged counts as finished, and the phase is validated once, as a whole. The launch bound is the lane limit or the usage ceiling, whichever is lower: `run_ceiling_usd` and `task_estimate_usd` (default $6) in the profile set it, and a phase that cannot start for want of headroom ends with a `paused` record naming the binding limit and the free slots. The decompose report and the dash feed carry the waves, the widest wave, and each phase's wave, lane, status and reason, and a chain whose bodies never name their upstream is reported as a single chain.

**Releases cut from a release branch.** The cut no longer freezes main. It creates `release/<version>` from the rehearsed commit, in coxswain and, when the release tags it, in dash. The bump pull request targets the release branch, the tags and the GitHub release are made at its head, and the tap formula reads it too. After the tags a merge-back pull request merges the release branch into the default branch with a merge commit, so the tag stays an ancestor of main, and the branch is deleted. A cut that stops part way resumes on a rerun: each finished step reports done and is skipped, and the rehearsal lookup uses the commit the branch was cut from. The chair's freeze stays available for an emergency, but it is not a step.

**Harness fixes.** A remote decompose launch detaches, so the chair tick no longer waits for a decompose to finish. A UI module's insta snapshots count as inside its surfaces when the module is a surface; a pending `.snap.new` does not count. A land whose work main already carries marks its tasks done instead of failing: a task land skips the empty cherry-pick, a phase land finds the pull request that carried it, and both report `landed via PR #n`, which the chair counts as a land.

**Towpath (dash #162).** A spend view by day and budget period. The feed's `budget` block parses on its own, so a bad one never drops the feed line, and towpath derives the verdict: over budget once spend reaches the budget, over pace once the projection exceeds it. With a month budget set, the spend view shows the month-to-date bar, the projection with the days left and the verdict, and today against the rolling daily average. Daily bars carry a marker at the average. The Slipstream rail's SPEND section picks its form from the feed: the budget form, the meters with their today lines, or a line saying no limit is configured. The Regatta spend frame draws the budget form in the rows it has, dropping the today line, then the projection, before the bar and verdict.
