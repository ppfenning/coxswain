# 0.33.0

Cut on 2026-10-06. Status: **beta**. This release works the follow-ups and the ideas list from running the chair
across three machines. Its headline starts moving the record of intake and tickets into the store: a decompose
writes rows and runs on any lane, and a relaunch goes to whichever machine has the most free lanes. The chair stops
relaunching while it lands, notices when lanes sit idle with work waiting, waits for every required check, and stops
hand-carrying phases whose approved commits never reached the phase branch. A crew dashboard shows each seat's cost,
approval rate, verdicts and causes (coxswain #239, coxswain #240).

**Toward the store as the only record.** A decompose writes its tickets as store rows and runs on any lane. A
relaunch goes to the machine with the most free lanes, the chair's own included, and moves off a busy home with a
fetch of its branches first. Pure helpers read an initiative's ready tasks from rows. The epic launch and the chair
do not export work/ from the store yet: the store holds no initiative rows and some task rows without content, so
filling it comes first, in 0.34.

**The chair lands what it approves.** A phase land gathers its approved tasks' commits when the phase branch is
missing them, which was behind most of the hand carries of the 0.32 night. The chair does not relaunch an
initiative while one of its phases is landing, detects a stall when lanes idle with work waiting and names the
blocker, and waits for every required check before a merge, rerunning a failed job once. A task quarantined on a
lane host is quarantined in the store, so the chair no longer relaunches its unchanged ticket.

**Runs say how they ended.** A run records its outcome at exit, and a run's history label reads that outcome,
showing blocked or refused with the reason. Needs-chair rows keep the arbitrated reason and remedy, and the inbox
lists them. The chair loop beats its own lease.

**Smaller things.** `cox settings` validates before writing and can commit a cartridge change. `cox` imports each
command's module only when that command runs. A lane host's launch gate reads the week's spend from the store, so
it no longer refuses at a figure several times the meter's when the meter reading is stale. The coxtop chair pane
stays up through drill-downs, and backtick puts focus back in it.

**Upgrading from 0.32.0.** Nothing migrates, and the store schema is unchanged. Restart the chair loop after
upgrading `cox`, still with `env -u FORCE_COLOR` under a shell that forces colour. Upgrade lane hosts too: a
relaunch may now be placed on any of them, and a lane host's launch gate needs tools #1415 to read the week's spend
correctly.
