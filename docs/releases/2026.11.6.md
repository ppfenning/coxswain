# 2026.11.6

Cut on 2026-11-09. Status: **beta**. This release is about the chair running without a person beside it. The chair now runs as a service that holds its own lease, and a session that starts beside it leaves it alone. The release gate, the steward and the steer rule no longer stop it from launching or merging. A machine that goes to sleep is marked unreachable instead of raising a login alert every hour. Towpath gets the start of the board view and a lighter feed.

**The chair keeps itself moving.** A session no longer takes the lease from a live chair service, and a session that holds it releases it when it exits. The chair breaks a steer deadlock: when initiatives hold each other's files only through approvals that cannot merge, it launches or releases one of them. It also sends one event when it sits idle with ready work. It says why it did not launch each ready initiative. It honours holds and a target release, and `target_release` names the release the work ships in, so work for the next release is open now.

**Landing.** The steward merges before the chair's own lands in a tick and waits for a busy repository instead of failing, and its merge step follows each initiative's `land_at`. A run the operator kills no longer costs its tasks an attempt. Lane hosts share a cap on pytest workers, so parallel lanes no longer overload a machine. A scheduler plans the whole queue as one graph and packs it onto lanes by critical path.

**Hosts.** A host that cannot be reached is marked unreachable after two checks, with one event when it goes and one when it returns. Orchestration mode, where the chair machine only plans, is an opt-in toggle that needs more than one active machine.

**Towpath.** Towpath shows building tasks in blue, the chair machine's orchestration mode, queued intakes with their stage, repo, epic, priority and target release, and each operator session's agents in the cost view. The feed recomputes only what changed, shares one process between towpath windows, and reports its own CPU cost, and towpath shows the feed's age and that cost.

## Known gaps

One pull request per initiative is not reliable yet. In this release's own development, phase branches fell behind main and conflicted, the steward's merges were locked out, and recovery steps held initiatives from launching, so the last part of 2026.11.6 landed each task as its own pull request (`land_at: task`). The fixes that make ticket landing run unattended move to 2026.11.7: a failing recovery step stops holding its initiative, the merge queue lands disjoint approvals in one pull request, phases of one wave run as separate lanes, and ticket landing no longer defers a done phase. The board view in towpath is partial: its page, layout, rows and feed parsing are in, and the tree frame, live panels and timeline follow in a towpath point release. The rest of the intake draft and ready work (fields CLI, feed producer, GitHub pull wiring), chair lane-checkout sync and the graphs flaky-test fixes also move to 2026.11.7.

Cut with `--allow-doc-drift`: `release-check` reports the same three drifts as at 2026.10.4 through 2026.11.5 (the dash component page lives at `docs/components/dash/`, the package description is two sentences, and `graphs/README.md` names the `agent-graphs` ledger directory).
