# 0.32.0

Cut on 2026-10-06. Status: **beta**. This release makes coxtop home: the curses screens are gone, and every view
they had now lives in coxtop. It also hardens the chair across machines after a night of running it from the Mac,
and carries the first parts of 0.33's follow-ups. The umbrella's README and docs landing page show coxtop
(coxswain #236), and the crew dashboard gains its cost and quarantine datasets (coxswain #234, coxswain #235).

**coxtop is home.** `cox home`, `cox console`, `cox runs top` and `cox setup` open coxtop on a terminal and keep
their `--once` and subcommand forms for scripts. The curses screens and their tests are deleted, and a test fails
if any module imports curses again. coxtop gains watch, spend and health drill-downs (`w`, `$`, `h`), fed by
schema-1 spend and health snapshots from `cox dash --detail`. The chair pane releases focus with Ctrl-] or a click
on another frame, shows the release key in its title, and Shift+Enter types a newline. coxtop adds and edits
initiatives, and listings and the dash feed show short ids beside slugs.

**The chair holds across machines.** The chair carries a stranded or split phase to its land and rebases a phase
branch that fell behind main. A run on the chair's own host homes there; a fetched remote run's store-held
approvals keep their run beside a local record, so they land instead of waiting on the chair; a phase land resumes
from a pull request it already opened. The store keeps every column a state write leaves out, the stranded check
follows a task that moved phase, and a deletion is no longer refused as a change outside its surfaces.

**First parts of 0.33.** The chair detects a stall when lanes idle with work waiting, pauses lands while the
forge's CI is down, and waits for every required check before merging. Needs-chair rows keep their reason and
remedy in the store, the chair loop beats its own lease, `cox settings` validates before writing, and the chair
reads lane stats to propose host lanes. A decompose-only chair hands homed work to a lane host.

**Upgrading from 0.31.0.** Nothing migrates, and the store schema is unchanged. Restart the chair loop after
upgrading `cox`; start it with `env -u FORCE_COLOR` when it runs under a shell that forces colour, or lands fail
the help-snapshot checks. The chair machine's lane count comes from its hosts-table row (`cox host capacity`).
