# 0.12.1

Cut on 2026-09-17. A patch: `coxswain-cartridges`, `coxswain-graphs` and `coxswain-tools` are tagged
`v0.12.1` in lockstep; `coxswain-crew` is unchanged and stays pinned at `v0.12.0`; `coxswain-tools` is
published to PyPI from its tag. Status: **beta**; nothing here breaks a `0.12.0` install. This release
fixes a fresh-machine install that had been broken since the repositories were renamed on 2026-09-05:
the installer looked for checkouts under names that no longer exist.

## coxswain-cartridges

- The plugin marketplace declares itself `coxswain-cartridges`, the repository's name since the rename;
  until now every Claude Code install registered the marketplace and the `local-skills` plugin as
  `agent-cartridges` (cartridges #81).

## coxswain-tools

- `cox setup install`, the setup and cartridge screens and the CLI's default provider profile and
  skills root build their paths from the `coxswain-*` checkout names. Under the old names a fresh
  install failed at its first step, `uv venv` in a directory that does not exist, and an existing
  install only worked because its profile had been repointed by hand. The marketplace the installer
  registers is now `local-skills@coxswain-cartridges` (tools #229).

## Known gaps

The cartridges Python distribution is still named `agent-cartridges`: the graphs `shell` extra and the
graphs CI checkout depend on that name, so the rename is a graphs-and-cartridges pair still ahead. The
routing profile stays at `~/.config/agent-tools/profile.yaml` and the `agent-tools` command alias
stays for this release, as planned. An install made before this release keeps its old marketplace
registration until `local-skills@agent-cartridges` and the `agent-cartridges` marketplace are removed
and `cox setup install --plugins` is rerun.

## Components

`coxswain-tools` and `coxswain-cartridges` carry the changes above; `coxswain-graphs` is re-tagged in
lockstep with no changes of its own; `coxswain-crew` is unchanged and stays pinned at `v0.12.0`.
