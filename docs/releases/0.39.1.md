# 0.39.1

Cut on 2026-10-13. Status: **beta**. A patch release that undoes one change from 0.39.0: bare `cox` opens the coxswain
Claude session again, as it did before towpath became the entry point. The towpath dashboard is its own command.

**Bare `cox` opens the session.** On a terminal, bare `cox` goes straight to the session, whether or not towpath or the
`coxtop` alias is installed. It no longer looks for a `coxtop` binary on the path. Run `cox home` to open the towpath
dashboard (bare `cox setup` opens it too); both find `towpath` first and fall back to `coxtop`. With no arguments and
output that is not a terminal, bare `cox` still prints the route status table. `cox session` is unchanged.

**Upgrading from 0.39.0.** Nothing to migrate. If you ran bare `cox` to open towpath, run `cox home` or `towpath`
instead. The Homebrew formula still installs `cox` and the `towpath` binary together.

## coxswain-tools

- Bare `cox` opens the session again: the `coxtop` exec path and its two helpers are removed from `main()`, the help
  text names `cox home` as the dashboard launcher, and tests cover bare `cox` with towpath installed, with neither
  binary, and `cox home` with only towpath (tools #1633).
