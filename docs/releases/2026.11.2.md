# 2026.11.2

Cut on 2026-11-03. Status: **beta**. This release collects the fixes from the first full day of a session chair driving a three-machine fleet through 2026.11.1. That day the Homebrew formula had to be fixed by hand, lanes were refused on hosts that had every tool they needed, and remote runs could not be fetched or landed without help. A plan with no five-hour limit also kept the usage gate holding on a limit that no longer existed. The release fixes those, makes `cox upgrade` refresh the towpath binary, and adds one store migration for the landing work that ships in later releases.

**The tap formula depends on libpq.** The release tooling no longer ships the psycopg-binary wheel in the Homebrew formula, which Homebrew could not relink. The formula now depends on `libpq` and wraps the `cox`, `agent-tools` and `cartridge` entry points with its library path, the shape 2026.11.1's tap PR was fixed to by hand.

**Usage on a plan with no five-hour limit.** A status-line meter whose `five_hour` is null used to be thrown away whole, so the gate paced on an older reading or a ceiling learned from the previous plan. Now it reads as "no five-hour limit": only the weekly window paces, the status line says `5h none`, a plan change drops the ceilings learned from the old plan, and towpath shows `no limit` for the window.

**Lanes and lands that need less help.** A lane host is no longer refused for a check tool that the repository's venv provides. `cox runs wait` fetches remote runs through the hosts table, as `cox runs fetch` does. An epic launch straight after a decompose fills the store first, so it finds the decompose's tasks. `cox route pull` skips an issue only when the same repository's issue is already filed, so a new issue is no longer skipped because an old row from another repository carries its number. A requeued intake drops its old initiative link. The decompose lint's contract correction names the fixture path it wants.

**Towpath.** `cox upgrade` installs the dash release's towpath binary. The runs box has its own PHASE column, a click no longer hides a card, and inbox entries begin to open to a detail view. The dash feed lists every task of each run's initiative with its stored state, tries and reason.

## Known gaps

Two initiatives are only partly in this release, and nothing calls their landed pieces yet. Intake queue control (coxswain #606) ships its store-level rules for `after:`, hold and release, intake priority and bulk remove, but the chair does not honour them and the `cox route` commands for them have not landed. Landing at a configurable granularity (#620) ships the store columns for a task's merge commit and handoff record (store migration 0015), local assembly of several parent branches, and a pure lane scheduler, but the epic driver still runs phase by phase and lands each phase as its own PR. Both are finished in a later release, and per-task lane scheduling moves to the waves-of-phases work (#626). The chair still performs each land inside its tick, so its ticks stretch while CI runs and launches wait behind them. The dash feed's task list is in this release; towpath's tree view of it is not. Five more fixes are in only in part: a remote fetch bringing back phase branches, taking a land lease from a dead process, a decompose writing its tasks as store rows, the inbox detail view, and the cross-repo contract fixture surviving the surface gates. Their first pieces are here; the rest follow.

Cut with `--allow-doc-drift`: `release-check` reports the same three drifts as at 2026.10.4 through 2026.11.1 (the dash component page lives at `docs/components/dash/`, the package description is two sentences, and `graphs/README.md` names the `agent-graphs` ledger directory).

## Upgrading

The store schema moves from version 14 to 15. Migration 0015 adds two nullable columns to `work_items`: `merged_commit` and `handoff_json`. No manual step is needed. The harness applies the migration the first time it opens the store to write, and it saves a backup copy first; a Postgres store needs `pg_dump` on the PATH for that backup. An older harness refuses to open a store at version 15, so upgrade every lane host that shares a store along with the chair. On a plan with no five-hour limit, a profile `window_ceiling_usd` no longer holds the gate, and any learned ceilings from an earlier plan are dropped on the first fresh reading. This release declares no `cox migrate` migrations.
