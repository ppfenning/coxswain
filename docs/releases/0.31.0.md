# 0.31.0

Cut on 2026-10-05. Status: **beta**. This release makes coxtop the place you run Coxswain from, and lets the chair run
with less hand-holding. It carries four headlines. Coxswain's own CI check jobs now read their runner from the
`COXSWAIN_RUNNER` repository variable, so they can move to a self-hosted runner while GitHub-hosted runners are down
(coxswain #230, coxswain #231).

**coxtop is the entry point.** Bare `cox` on a terminal opens coxtop. The settings screen reads and writes the team
cartridge and the hosts table, coxtop adds a machine and edits initiatives, and `cox route edit` and `cox route remove`
change or drop a filed initiative. The chair panel hosts a Claude session beside the pages: the backtick key opens and
hides it, and an ended session frees its keys. Dash releases attach prebuilt coxtop binaries.

**coxtop reads the fleet from the store.** The chair frame reads the chair's tick from the store, so it shows the
loop's health from any machine, with its tick age. The runs list says how each run ended, history marks an idle run
as idle instead of crashed, every Regatta frame carries its number, and a run drill-down opens even when the store
has not placed the run on a machine yet.

**The chair steers clear and carries.** The chair holds back a launch whose surfaces overlap a live run, carries a
stranded or split phase to its land, gives a free local lane one decompose with no pairing, and skips a lane host
whose login has lapsed instead of fetching from it.

**Keys that do one thing.** Layout cycles on `v`, so `p` is only run pause; selection is arrows only, so `k` is only
kill; and Slipstream follows the `t` theme.

**Upgrading from 0.30.0.** Nothing migrates, and the store schema is unchanged. Restart the chair loop after
upgrading `cox`, so it writes the chair tick that coxtop now reads. The `policy.dispatch.local_lanes: decompose`
reservation is no longer needed; remove it from the team cartridge. coxtop's watch, spend and health views are
partly built (their schemas, stubs and boards are here) and open in 0.32.0.

## Components

`coxswain-tools` carries bare `cox`, settings, route edit and remove, the store-read chair and the chair's
steer-clear and carry; `coxswain-dash` carries the settings, add-machine and edit screens, the session panel, the
runs list and the key fixes. `coxswain-graphs`, `coxswain-cartridges` and `coxswain-crew` carry only the CI runner
variable.
