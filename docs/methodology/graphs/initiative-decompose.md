# initiative-decompose

The coxswain dispatches initiative-decompose during scoping, before any
ticket is planned: it reads an initiative and proposes the epics and
tickets that would carry it. What lands is a draft decomposition for a
human to accept, trim, or reshape, never tickets filed directly onto the
active board.
