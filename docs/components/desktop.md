# Desktop

Desktop is a desktop shell around the HUD, for running it as a native
window instead of a browser tab.

## What it owns

Unlike the other five components, desktop is not a separate repository: it
lives in this repository's `desktop/` directory and is pinned by path, not
by tag.

## Installing it

Desktop is optional. Install it with:

```
cox install --with desktop
```

## Its own docs

Desktop's own docs live in this repository, under `desktop/`.
