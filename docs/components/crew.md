# Crew

The crew is the agents that do the rowing: they plan, build, review, and
validate. The coxswain steers; the crew rows.

## What it owns

The `crew` folder holds eleven seat definitions — recon, triage, build,
review, ops, the board, writing, the scribe, the steward, the courier and the
model steward — each one role filled by one agent doing one job.

## Installing it

`cox install` and `cox upgrade` link every seat from `<checkout>/crew` into
`~/.claude/agents`. Nothing to pass.
